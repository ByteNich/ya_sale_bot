# 🤖 Яндекс.Маркет Бот - Мониторинг Скидок

Telegram бот для автоматического мониторинга цен и скидок на товары Яндекс.Маркета.

## 🌟 Возможности

- 📊 **Мониторинг категорий**: Отслеживание цен в выбранных категориях (смартфоны, телевизоры, ноутбуки и др.)
- 💰 **Уведомления о скидках**: Мгновенные уведомления при обнаружении значительных скидок
- 📈 **История цен**: Сохранение истории изменения цен для каждого товара
- ⚙️ **Гибкие настройки**: Настройка интервала проверки и порога скидок
- 📂 **Управление категориями**: Добавление, удаление и настройка категорий товаров
- 📊 **Статистика**: Подробная статистика по категориям и товарам
- 🔄 **Автоматическое обновление**: Регулярная проверка цен (по умолчанию каждые 2 минуты)

- **Python 3.11+**

- **PostgreSQL** - база данных
- **APScheduler** - планировщик задач для мониторинга
- **aiohttp** - асинхронные HTTP-запросы
- **BeautifulSoup4** - парсинг HTML

## 📦 Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/ByteNich/ya_sale_bot.git
cd ya_sale_bot
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Настройка переменных окружения

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Отредактируйте `.env` и заполните необходимые данные:

```env
# Telegram Bot Configuration
BOT_TOKEN=your_bot_token_from_botfather
ADMIN_IDS=123456789,987654321  # Ваши Telegram ID (можно узнать у @userinfobot)

# Database Configuration
DATABASE_URL=postgresql+asyncpg://user:password@localhost:5432/ya_sale_bot

# Parser Configuration
CHECK_INTERVAL=120  # Интервал проверки в секундах (2 минуты)
DISCOUNT_THRESHOLD=10  # Минимальный процент скидки для уведомлений
```

### 4. Создание базы данных

Создайте PostgreSQL базу данных:

```sql
CREATE DATABASE ya_sale_bot;
```

### 5. Запуск бота

```bash
python main.py
```

## 🚀 Деплой на Railway

### 1. Подготовка проекта

Проект уже содержит все необходимые файлы для деплоя на Railway:
- `Procfile` - команда запуска
- `railway.json` - конфигурация Railway
- `runtime.txt` - версия Python
- `requirements.txt` - зависимости

### 2. Создание проекта на Railway

1. Зарегистрируйтесь на [Railway.app](https://railway.app)
2. Создайте новый проект "New Project"
3. Выберите "Deploy from GitHub repo"
4. Выберите репозиторий `ya_sale_bot`

### 3. Добавление PostgreSQL

1. В проекте нажмите "New" → "Database" → "Add PostgreSQL"
2. Railway автоматически создаст базу данных и установит переменную `DATABASE_URL`

### 4. Настройка переменных окружения

В настройках проекта Railway добавьте переменные:

```
BOT_TOKEN=your_bot_token
ADMIN_IDS=your_telegram_id
CHECK_INTERVAL=120
DISCOUNT_THRESHOLD=10
```

**Важно**: `DATABASE_URL` уже будет установлена автоматически при добавлении PostgreSQL.

### 5. Деплой

Railway автоматически задеплоит приложение после коммита в репозиторий.

## 📱 Использование бота

### Команды

- `/start` - Главное меню
- `/admin` - Административная панель

### Основные функции

#### 📂 Управление категориями

1. Откройте "Управление категориями"
2. Нажмите "Добавить категорию"
3. Выберите категорию из предустановленных или введите свою

- **Интервал проверки**: Как часто проверять цены (1 мин - 1 час)
- **Порог скидки**: Минимальный процент скидки для уведомлений (5% - 50%)

#### 🔍 Мониторинг

- Запуск/остановка автоматического мониторинга
- Просмотр статуса и последнего обновления
- Принудительная проверка цен

#### 📊 Статистика

- Общая статистика по товарам и категориям
- Топ скидок
- История цен
- Лучшие предложения

## 📝 Логирование

Логи сохраняются в файл `bot.log` и выводятся в консоль.

Уровни логирования:
- `INFO` - основные события
- `WARNING` - предупреждения
- `ERROR` - ошибки

## ⚠️ Важные замечания

1. **Парсинг Яндекс.Маркета**: Яндекс.Маркет регулярно меняет структуру страниц. Если парсер перестал работать, возможно потребуется обновить селекторы в `parser/yandex_market.py`

2. **Rate Limiting**: Не устанавливайте слишком маленький интервал проверки (менее 1 минуты), чтобы избежать блокировки IP

3. **База данных**: Убедитесь, что PostgreSQL доступен и правильно настроен

4. **Токен бота**: Храните токен в безопасности, не коммитьте `.env` в репозиторий
